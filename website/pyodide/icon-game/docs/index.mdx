# Icon-Spiel

Mit `@gameloop` aktualisiert Python eine Szene regelmässig und verarbeitet dabei Browser-Ereignisse.

```py live_pyo id=f75518ac-7c35-452f-a756-2a83f18e25fc title=icon-game.py
from random import randint, choice, sample
from webio import gameloop, run
from icon_game import use_scene
from itertools import combinations 

SPEED_FACTOR = 20
ICON_COUNT = 5
DIM_X = 400
DIM_Y = 600

scene = use_scene('icon-game')
scene.reset()
scene.configure(width=DIM_X, height=DIM_Y, background_color='black')
scene.render()
colors = ['yellow', 'gold', 'orange', 'red', 'maroon', 'violet', 'magenta', 'purple', 'navy', 'blue', 'skyblue', 'cyan', 'teal', 'turquoise', 'lawngreen', 'green', 'darkgreen', 'chocolate', 'brown', 'gray', 'white']
icons = ['emoticon-poop','emoticon-lol','emoticon-tongue','emoticon-wink','emoticon-cool','emoticon-devil','emoticon-excited','emoticon-confused','emoticon-dead','emoticon-kiss','emoticon-happy','emoticon-cry','emoticon-angry','emoticon-sick','mushroom','alien','alien-outline','ghost','ghost-outline','ghost-off','robot','robot-happy','robot-confused','robot-excited','robot-love','robot-dead','robot-angry','robot-vacuum','duck','penguin','owl','cat','dog','dog-side','pig','pig-variant','cow','sheep','rabbit','rabbit-variant','snail','unicorn','unicorn-variant','jellyfish','pizza','shark','shark-fin','bat','spider','turkey']


def random_speed(ico, randomize_all = False):
    ico.speed_x = randint(-5 * SPEED_FACTOR, 5 * SPEED_FACTOR)
    ico.speed_y = randint(-5 * SPEED_FACTOR, 5 * SPEED_FACTOR)
    ico.color = choice(colors)
    if randomize_all:
        ico.size = randint(8, 20)
        ico.x = randint(0, DIM_X)
        ico.y = randint(0, DIM_Y)

for name in sample(icons, ICON_COUNT):
    x = randint(0, DIM_X)
    y = randint(0, DIM_Y)
    size = randint(8, 20)
    ico = scene.add_icon(name)
    random_speed(ico, True)

def rect(ico):
    return [
        ico.x - ico.size,
        ico.y + ico.size,
        ico.x + ico.size,
        ico.y - ico.size
    ]
    
def is_colliding(a, b):
    a_left, a_top, a_right, a_bottom = rect(a)
    b_left, b_top, b_right, b_bottom = rect(b)
    return b_left < a_right and b_right > a_left and b_top > a_bottom and b_bottom < a_top


def update_icons(dt):
    for a, b in combinations(scene.icons, 2):
        if is_colliding(a, b):
            random_speed(a)
            random_speed(b)
    for ico in scene.icons:
        if ico.x > DIM_X or ico.x < 0:
            ico.speed_x = -ico.speed_x
        if ico.y > DIM_Y or ico.y < 0:
            ico.speed_y = -ico.speed_y
        ico.x = ico.x + ico.speed_x * dt
        ico.y = ico.y + ico.speed_y * dt
        ico.rotation = ico.rotation + 45 * dt

@gameloop(fps=120, sources=[scene])
def update(ctx):
    update_icons(ctx.dt)
    scene.render()

await run()
```

Die Geschwindigkeiten sind in Pixeln pro Sekunde angegeben. `ctx.dt` berücksichtigt die tatsächlich vergangene Zeit zwischen zwei Bildern. `scene.render()` überträgt alle Änderungen eines Bildes gemeinsam an den Browser. Details zum Ablauf stehen in der [webio-Referenz](../../02-webio.mdx#spielschleife).

## Szene und Icons

`configure(show_fps=False)`
: Blendet die kleine FPS-Anzeige oben rechts aus; mit `show_fps=True` wird sie wieder eingeblendet. Standard: `True`. Die Anzeige misst die Aufrufe von `scene.render()` im Worker über ungefähr eine halbe Sekunde. Die Einstellung wird mit dem nächsten `scene.render()` sichtbar. Ohne laufendes Programm zeigt die Anzeige `0 FPS`.

`sceneId`
: Verbindet die React-Komponente mit `use_scene(id)`. Mehrere Ansichten derselben ID teilen ihre Anzeige.
`use_scene(id)`
: Liefert innerhalb derselben Ausführung denselben lokalen Handle zurück.
`configure(width=400, height=800, background_color='black')`
: Legt die logische Grösse und Hintergrundfarbe fest. Die Darstellung verkleinert sich bei wenig Platz proportional; Spielkoordinaten bleiben unverändert.
`width`, `height`
: Logische Breite und Höhe der Szene in Pixeln.
`reset()`
: Entfernt alle Icons und behält die Konfiguration bei.
`add_icon(name, x=width/2, y=height/2, size=width*0.1, color='white', speed_x=0, speed_y=0, rotation=0)`
: Erzeugt ein Icon mit dem MDI-Namen `name`, beispielsweise `'mdiSnowflake'`, `'mdiCircle'` oder `'mdiRocketLaunch'`. Camel-Case und Dash-Case sind mit oder ohne MDI-Präfix erlaubt: `'mdiAlarmPlus'`, `'alarmPlus'`, `'mdi-alarm-plus'` und `'alarm-plus'` ergeben dasselbe Icon. Das gilt auch beim Ändern von `icon.name`; der Handle behält die eingegebene Schreibweise. Unbekannte Namen werden beim Hinzufügen und beim Rendern abgewiesen. `size` ist die halbe Symbolgrösse in Pixeln; `(x, y)` ist die Mitte. `color`, `speed_x`, `speed_y` und `rotation` werden als benannte Argumente übergeben.
`icons`
: Momentaufnahme der aktuellen Handles in der Reihenfolge des Hinzufügens. Später hinzugefügte Icons liegen über früheren. Während der Iteration können Icons entfernt werden.
`scene.add_icon('alarm-plus')`
: Ohne Positions- und Grössenangaben liegt das Icon in der Mitte der aktuellen Szene: `x = scene.width / 2`, `y = scene.height / 2`, `size = scene.width * 0.1`. `size` bleibt die halbe Symbolgrösse. Die Standardwerte werden beim Hinzufügen berechnet; spätere Änderungen der Szenengrösse verändern bestehende Icons nicht.
`icon.name`, `icon.x`, `icon.y`, `icon.size`, `icon.speed_x`, `icon.speed_y`, `icon.color`, `icon.rotation`
: Veränderbare Eigenschaften eines Icons. Änderungen werden beim nächsten `render()` sichtbar. Die Bewegung mit `speed_x` und `speed_y` legt der Python-Code fest.
`size`
: Veränderbare halbe Symbolgrösse in Pixeln. Zum Beispiel vergrössert `icon.size += 2 * ctx.dt` das Icon innerhalb der Update-Funktion. Die Grösse muss positiv und endlich bleiben; die Änderung wird beim nächsten `scene.render()` sichtbar.
`icon.name_short`
: Schreibgeschützter Name in Dash-Case ohne MDI-Präfix, beispielsweise `'alarm-plus'`. Wird aus `icon.name` abgeleitet und passt sich bei Namensänderungen automatisch an.
`speed_x`, `speed_y`
: Veränderbare Geschwindigkeiten in Pixeln pro Sekunde; beide standardmässig `0`. Positive Werte zeigen nach rechts bzw. unten. Der Python-Code aktualisiert `x` und `y` mit der jeweiligen Geschwindigkeit und `ctx.dt`.
`rotation`
: Drehung in Grad um die Mitte des Icons, positiv im Uhrzeigersinn. Standard: `0`. Negative Werte und Werte über `360` sind erlaubt; der Wert muss endlich sein.
`remove_icon(icon)`
: Entfernt den angegebenen Handle aus der Szene.
`color`
: CSS-Farbe als Zeichenkette, beispielsweise `'white'`, `'lightblue'` oder `'#ff8800'`. Standard: `'white'`.
`render()`
: Überträgt den aktuellen Zustand der ganzen Szene. Änderungen an Handles, `configure()` und `reset()` werden erst damit sichtbar.
`events`
: Ereignisquelle für `@gameloop`, `@on_click` und weitere Handler aus `webio`.

Klick-Ereignisse enthalten `event.x` und `event.y` in logischen Szenenkoordinaten, auch bei verkleinerter Darstellung. Dieselben Werte stehen in `event.payload['x']` und `event.payload['y']`. Tastatureingaben gehen an die fokussierte Szene und enthalten den Tastennamen in `event.payload['key']`.

Kreise sind ebenfalls Icons. Symbol, Position, Farbe und Drehung lassen sich über den Handle ändern:

```py
icon = scene.add_icon('mdiCircle', 200, 400, 6, color='#ff8800')
icon.x += 10
icon.size = 24
icon.name = 'mdiRocketLaunch'
icon.color = 'yellow'
icon.rotation = 90
scene.render()
```

## Zustand und Lebensdauer

Die Browser-Anzeige bleibt nach Ende oder Abbruch eines Skripts erhalten. Ein neuer Python-Handle beginnt mit den Standardwerten und ohne Icons. Sein erster `render()` ersetzt die bisherige Anzeige. Mit `reset()` und `configure()` am Skriptanfang lässt sich der gewünschte Startzustand ausdrücklich festlegen.

## Auf der eigenen Website einrichten

Voraussetzung ist das [installierte Pyodide-Package](../../README.mdx#installation).

<Steps>

1. Kopiere den vollständigen Ordner [icon-game](https://github.com/GBSL-Informatik/teaching-dev/tree/main/tdev-website/website/pyodide/icon-game) nach __website/pyodide/icon-game__.
2. Ergänze den Ordner in der bestehenden `extensions`-Liste des [Pyodide-Plugins](../../README.mdx#erweiterungen-registrieren):

    ```ts title="siteConfig.ts"
    extensions: [
        './website/pyodide/icon-game'
    ]
    ```

3. Starte den Entwicklungsserver neu. Danach kannst du das MDX-Beispiel oben verwenden.

</Steps>

Die __extension.json__ im kopierten Ordner legt den Namen und die Einstiegspunkte fest. Der Browser-Store wird automatisch initialisiert; der `SiteStore` deiner Website benötigt keine Ergänzungen.
