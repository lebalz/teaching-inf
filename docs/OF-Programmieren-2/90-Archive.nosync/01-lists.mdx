# 1. Listen

Zum Speichern von **mehreren Werten** unter einem **einzigen Namen** werden beim Programmieren Listen oder Arrays verwendet. __Listen__ sind vergleichbar mit einspaltigen Tabellen. Die Zellen in der Tabelle werden als **Elemente** bezeichnet und sind durchnummeriert. So können einzelne Werte, die in der Liste gespeichert sind, voneinander unterschieden werden. Die Nummer eines Elements wird als dessen **Index** bezeichnet.

:::warning[Wichtig]
- Das erste Element in der Liste trägt den Index 0.
- Der Index des letzten Elementes ist somit die Länge der Liste minus 1.
:::

Die folgende Auflistung illustriert dies für eine Liste mit 4 Noten. Die **Länge** der Liste ist **4**, das letzte Element trägt den **Index 3**.

Index
: **Wert**
`0`
: :mdi[arrow-right-thin] `4.5`
`1`
: :mdi[arrow-right-thin] `5`
`2`
: :mdi[arrow-right-thin] `3.5`
`3`
: :mdi[arrow-right-thin] `5.5`

In Python lassen sich Listen mit eckigen Klammern `[ ]` wie folgt erzeugen:

```py live_py slim
noten = [4.5, 5, 3.5, 5.5]
print('Die vierte Note war eine', noten[3])
```

Im Beispiel wird die vierte Note mit dem Index `3` ausgegeben.

::::def[Schleife über alle Elemente der Liste]
Anstatt mit `range()` einen Schleifeniterator zu erzeugen, kann auch direkt eine
explizite Liste angegeben werden. Die **Laufvariable** nimmt dabei nacheinander die Werte der Liste an.

```py live_py slim
noten = [3.5, 6, 5, 4.5]

for note in noten:
    print(note)
```
:::insight[Laufvariable]
Die Laufvariable `note` nimmt in jedem Schleifendurchlauf den Wert des nächsten Elements der Liste `noten` an.
:::
::::

::::def[Schleife über Listen-Indices]
```py live_py slim
noten = [3.5, 6, 5, 4.5]

länge = len(noten)  # Länge der Liste ermitteln

for i in range(länge):
    print(i, ":", noten[i])
```
:::insight[`range(länge)`]
Für die Arbeit mit Listen ist es sehr praktisch, dass der Schleifenzähler `i` genau die Indexwerte der Liste annimmt.
:::

## Elemente abfragen


:::def[Erstes Element: `<liste>[0]`]
```py live_py slim
noten = [4.5, 5, 3.5, 5.5]
print(noten[0])
```
:::


:::def[Letztes Element `<liste>[-1]`]
```py live_py slim
noten = [4.5, 5, 3.5, 5.5]
print(noten[-1])
# oder gleichbedeutend
print(noten[len(noten) - 1])
```
:::

::::def[Fehler: <span className="badge badge--danger">IndexError</span>]
Fragt man einen Index ab, den es nicht gibt (weil es zu wenige Elemente in der Liste hat), so entsteht ein <span className="badge badge--danger">IndexError</span>.

```py live_py slim
noten = [3.5, 6, 5, 4.5]

# Eine Liste mit 4 Elementen: Grösster Index ist 3
print(noten[4])  # IndexError: list index out of range
```
:::insight[Fehlerbehebung]
- Prüfen Sie die Länge der Liste mit `len(<liste>)`.
- Prüfen Sie, ob der Index kleiner als die Länge der Liste ist.

```py live_py slim
noten = [3.5, 6, 5, 4.5]
if len(noten) > 4:
    print(noten[4])
```
:::

## Elemente Verändern

:::def[Zuordnung: `<liste>[index] = <wert>`]

Ein Element in der Liste kann durch eine Zuordnung verändert werden. Im untenstehenden Beispiel werden alle ungenügenden Noten auf eine `5` gesetzt.
```py live_py slim
noten = [4.5, 5, 3.5, 5.5]
for i in range(len(noten)):
    if noten[i] < 4:
        noten[i] = 5
print(noten)
```
:::

::::aufgabe[Roboter mit Morgenmuffel-Akku]
Fünf Haushaltsroboter sollen aufräumen. Einige haben aber kaum noch Energie und behaupten,
sie seien «im Energiesparmodus». Die Liste enthält ihre Akkustände in Prozent.

Gehen Sie mit einer Schleife über alle Indizes. Jeder Akkustand **unter 20** soll um
**30 Prozentpunkte** erhöht werden; die anderen Werte bleiben gleich.

:::warning[Hinweis]
Schreiben Sie die fertige Ergebnisliste nicht direkt in den Code.
:::

Zur Kontrolle: Aus der vorgegebenen Liste soll `[45, 80, 35, 60, 30]` werden.
Testen Sie danach mit `[20, 19, 100]`: Das Ergebnis muss `[20, 49, 100]` sein.

```py live_py title=morgenmuffel-akku.py id=af994950-d98b-474b-8b02-a4881c880440
akkus = [15, 80, 5, 60, 0]
# Laden Sie nur die müden Roboter auf.
```

<Solution id="c2a20fcb-43cc-4bf7-bfc3-e11dfbd36bb4">

```py
akkus = [15, 80, 5, 60, 0]
for index in range(len(akkus)):
    if akkus[index] < 20:
        akkus[index] = akkus[index] + 30
print(akkus)
```

Die Zuweisung verändert das Element an der aktuellen Position. Ein Akkustand von genau 20 bleibt unverändert.
</Solution>

## Elemente Hinzufügen/Entfernen

::::def[hinzufügen: `<liste>.append(<wert>)`]

`append` fügt ein neues Element am **Ende** der Liste hinzu.

```py live_py slim
noten = [4.5, 5, 3.5, 5.5]
print('Ursprünglich', noten)
noten.append(6)
print('Neu', noten)
```
:::details[An beliebiger Stelle einfügen: `<liste>.insert(<index>, <wert>)`]

```py live_py slim
noten = [4.5, 5, 3.5, 5.5]
print('Ursprünglich', noten)
noten.insert(1, 6) # Bei Index 1 (2. Stelle) wird eine 6 eingefügt
print('Neu', noten)
```
:::
::::

:::def[entfernen: `<liste>.pop(<index>)`]
Entfernt das Element an der Stelle `index` und gibt dieses zurück:

```py live_py slim
noten = [4.5, 5, 3.5, 5.5]
entfernt = noten.pop(2)
print('Entfernt', entfernt)
print('Noten', noten)
```
:::

:::def[Aufsteigend sortieren `<liste>.sort()`]
```py live_py slim
noten = [3.5, 6, 5, 4, 4.5, 5]

noten.sort()
print(noten)
```
:::

## Listen Untersuchen

:::def[Maximum: `max(<liste>)`]
Gibt das maximale Element einer numerischen Liste zurück

```py live_py slim
noten = [4.5, 5, 3.5, 5.5]
print('Beste Noten', max(noten))
```
:::

:::def[Minimum: `min(<liste>)`]
Gibt das minimale Element einer numerischen Liste zurück

```py live_py slim
noten = [4.5, 5, 3.5, 5.5]
print('Schlechteste Noten', min(noten))
```
:::

:::def[Wert in einer Liste? `<wert> in <liste>`]
Überprüft, ob sich ein Wert in einer Liste befindet

```py live_py slim
noten = [4.5, 5, 3.5, 5.5]
if 6 in noten:
    print('Glückwunsch, du hast min. einmal eine 6 geschrieben')
else:
    print('Du hast noch keine 6 geschrieben')
```
:::

:::def[Anzahl Elemente mit einem Wert? `<liste>.count(<wert>)`]
Zählt, wie oft sich ein Wert in einer Liste befindet. 

```py live_py slim
noten = [4.5, 5, 3.5, 5.5, 5]
for i in [1, 1.5, 2, 2.5, 3, 3.5, 4, 4.5, 5, 5.5, 6]:
    if noten.count(i) > 0:
        print(f'Anzahl {i}: {noten.count(i)}')
```
:::

::::aufgabe[Schnarch-O-Meter im Klassenlager]
Ein Messgerät hat die Schnarchlautstärke im Schlafsaal gemessen: `0` bedeutet Stille,
`9` bedeutet «Ein Traktor schläft im oberen Bett».

Erstellen Sie aus den Messwerten einen kurzen Bericht:

1. Geben Sie mit `max()` und `min()` den lautesten und den leisesten Wert aus.
2. Berechnen Sie den Unterschied zwischen diesen beiden Werten und geben Sie ihn aus.
3. Zählen Sie mit `count()`, wie oft die Lautstärke `9` gemessen wurde.
4. Prüfen Sie mit `in`, ob eine `0` vorkommt. Geben Sie dann `Endlich Ruhe!` aus, andernfalls `Nicht einmal die Socken konnten schlafen.`
5. Testen Sie Ihren Code mit der verborgenen Liste `klassenlager`, welche 23 zufällige Messwerte enthält.

Zur Kontrolle: Maximum `9`, Minimum `1`, Unterschied `8`, drei Traktormomente und keine Stille.
Ersetzen Sie danach den ersten Messwert durch `0` und prüfen Sie, ob sich Ihr Bericht passend ändert.

```py live_pyo title=schnarch-o-meter.py id=353ffeae-c8ac-44ff-9fe4-fcc47739db5b
from random import choices
klassenlager = choices(range(10), k=23)
### PRE
lautstärken = [2, 9, 4, 9, 1, 9]
# Werten Sie die nächtlichen Geräusche aus.
```

<Solution id="aa8b557e-49b4-4281-a4a0-14aaac887eff">

```py
lautstärken = [2, 9, 4, 9, 1, 9]
lauteste = max(lautstärken)
leiseste = min(lautstärken)
print('Maximum:', lauteste)
print('Minimum:', leiseste)
print('Unterschied:', lauteste - leiseste)
print('Traktormomente:', lautstärken.count(9))
if 0 in lautstärken:
    print('Endlich Ruhe!')
else:
    print('Nicht einmal die Socken konnten schlafen.')
```

Mit einem ersten Messwert von `0` sinkt das Minimum auf 0, der Unterschied steigt auf 9
und die letzte Ausgabe lautet `Endlich Ruhe!`. Die Zahl der Traktormomente bleibt gleich.
</Solution>
