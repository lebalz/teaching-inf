# Linienfolger

Die Anordnung und Kalibrierung der Liniensensoren (__L2__, __L1__, __M__, __R1__, __R2__) ist auf der Seite "Liniensensoren" beschrieben.

:::note[Referenz]
Micro\:Bit Editor
: [https://python.microbit.org/v/3](https://python.microbit.org/v/3)
Maqueen Bibliothek
: [https://gbsl-informatik.github.io/maqueen-plus-v2-mpy/](https://gbsl-informatik.github.io/maqueen-plus-v2-mpy/)
:::

Ein einfacher Ansatz für einen Linienfolger wäre, die Liniensensoren immer zu überprüfen und entsprechend die Motoren anzusteuern:

Standard
: Geradeaus fahren
Sensor L1 = 1 und M = 0
: Linkskurve, da nun zu weit rechts
Sensor R1 = 1 und M = 0
: Rechtskurve, da nun zu weit links

In Python würde dies etwa so aussehen:

```python
from microbit import *
from maqueen import *

# recalibrate() # mit A-Taste Kalibrierung starten und Werte in `calibrate()` anpassen
calibrate([80, 80, 80, 80, 80]) # todo: Kalibrierung anpassen!

while True:
    sensoren = line_sensor_all()
    motor_run(Motor.ALL, 40)
    if sensoren[1] == 1 and sensoren[2] == 0:
        motor_run(Motor.LEFT, 0)
        motor_run(Motor.RIGHT, 40)
    elif sensoren[3] == 1 and sensoren[2] == 0:
        motor_run(Motor.LEFT, 40)
        motor_run(Motor.RIGHT, 0)
```

## Zustandsdiagramm
Um den Linienfolger robuster und zuverlässiger zu machen, braucht es eine **Zustandsmaschine**. Der Roboter ist zu jedem Zeitpunkt nur in genau einem Zustand. Abhängig von den Sensorwerten wird dann der Zustand gewechselt. In jedem Zustand ist zudem definiert, wie die Motoren angesteuert werden.

:::cards{cols="2" width="390px"}
Im Unterricht haben wir folgendes Zustandsdiagramm erarbeitet:

![](./images/simple-line-follower-state-diagram.svg)

::br
In Python wurde dieses Zustandsdiagramm wie folgt umgesetzt:

```python
from microbit import *
from maqueen import *

zustand = 'vorwärts'

# Zustandsmaschine umsetzen
while True:
    sensoren = line_sensor_all()
    if zustand == 'vorwärts':
        motor_run(Motor.ALL, 40)
        if sensoren[2] == 1:
            zustand = 'vorwärts'
        elif sensoren[1] == 1:
            zustand = 'linkskurve'
        elif sensoren[3] == 1:
            zustand = 'rechtskurve'
    elif zustand == 'linkskurve':
        motor_run(Motor.LEFT, 0)
        motor_run(Motor.RIGHT, 40)
        # TODO: die Sensorwerte verarbeiten
    elif zustand == 'rechtskurve':
        motor_run(Motor.LEFT, 40)
        motor_run(Motor.RIGHT, 0)
        # TODO: die Sensorwerte verarbeiten
```
:::

:::insight[Bemerke]
Mit diesem Zustandsdiagramm ist es nicht möglich, von einer Rechtskurve direkt zu einer Linkskurve überzugehen.
:::

Mit diesem Ansatz ist es nun auch möglich, den Roboter zuverlässig auf der Linie zu halten, da der aktuelle Zustand **beibehalten** wird, bis die Sensoren einen **Zustandswechsel auslösen**.

![](./images/maqueen-line-sensor-with-state.png)

:::insight[Zustandsübergänge]
Zustandsübergänge werden **nur durch die Sensoren** ausgelöst. Somit spielt es keine Rolle, wenn im Zustand __linkskurve__ der Sensor __L1__ plötzlich wieder weiss sieht. Der Roboter wird weiterhin eine Linkskurve fahren, bis der Sensor __M__ wieder schwarz detektiert und somit in den Zustand __vorwärts__ übergangen wird.
:::

## Ecken erkennen

Obiger Ansatz funktioniert gut, aber nicht perfekt.

![](./images/maqueen-line-sensor-rectangle.png)

:::tip[Ecken erkennen]{.compactDeflist}
Zeitpunkt 1
: Der Maqueen fährt im Zustand __Vorwärts__ auf der Linie.
: __Vorwärts__-Zustand
: __M__ sieht schwarz
Zeitpunkt 2
: Der Maqueen bleibt im __Vorwärts__-Zustand, da der Sensor __M__ weiterhin schwarz sieht. Das passt soweit ✅.
: __L1__ und __M__ sehen schwarz
Zeitpunkt 3
: alle Sensoren weiss, keine Bedingung in der `if-elif` Abfrage trifft zu, also bleibt der __Vorwärts__-Zustand unverändert.
Zeitpunkt 4
: Der Seitensensor __L2__ sieht schwarz. Dies ist der entscheidende "Hinweis", dass es sich um eine linke Ecke handelt.
: __L2__ sieht schwarz
: Übergang zu :mdi[arrow-right] __Linkskurve__-Zustand 
: **Achtung**: Es können Spezialfälle auftreten!
:::
