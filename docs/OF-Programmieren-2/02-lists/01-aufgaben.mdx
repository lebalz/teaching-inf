## Tastendruck erkennen

Auf dem Micro:Bit können die beiden Tasten `A` und `B` abgefragt werden. Es gibt zwei Möglichkeiten, den Zustand der beiden Knöpfe abzufragen:

`is_pressed()`
: Prüft, ob die Taste gerade gedrückt ist (True/False).
`was_pressed()`
: Prüft, ob die Taste seit dem Programmstart oder dem letzten Aufruf von `was_pressed()` für diese Taste gedrückt wurde (True/False). Der Aufruf setzt diese gespeicherte Information für die abgefragte Taste zurück.

Beispiel

:::cards{flexBasis="250px"}
**Beispiel 1**
```py
from microbit import *

while True:
    if button_a.is_pressed():
        display.show(Image.HAPPY)
    elif button_b.is_pressed():
        display.show(Image.SAD)
    else:
        display.show(Image.ASLEEP)
```
::br
**Beispiel 2**
```py
from microbit import *

while True:
    if button_a.was_pressed():
        display.show(Image.HAPPY)
    elif button_b.was_pressed():
        display.show(Image.SAD)
    sleep(1000)
```
:::

<ChoiceAnswer multiple correct={[1, 3]}>
**Beispiel 1**: Beide Tasten werden gleichzeitig gedrückt. Welche Aussagen sind korrekt?

1. Es wird `Image.HAPPY` angezeigt.
2. Das Display wechselt in jedem Durchlauf von `Image.HAPPY` zu `Image.SAD`.
3. Weil die `if`-Bedingung für Taste `A` wahr ist, wird die `elif`-Bedingung für Taste `B` nicht mehr geprüft.
4. Weil beide Tasten gedrückt sind, wird der `else`-Block ausgeführt und `Image.ASLEEP` angezeigt.

<Hint when="assessed">
`button_a.is_pressed()` liefert `True`. Deshalb wird `Image.HAPPY` angezeigt.
In einer `if`/`elif`/`else`-Struktur wird nur der erste zutreffende Zweig ausgeführt.
Während beide Tasten gedrückt bleiben, hat daher der Zweig für `A` Vorrang.
</Hint>
</ChoiceAnswer>

<ChoiceAnswer multiple correct={[2, 4]}>
**Beispiel 2**: Während der Pause bei `sleep(1000)` wird zuerst kurz `A`
und danach `B` gedrückt. Beide Tasten sind vor dem Ende der Pause wieder losgelassen.
Welche Aussagen über die folgenden Schleifendurchläufe sind korrekt?

1. Beide Tastendrücke gehen verloren, weil beim Ende der Pause keine Taste mehr gedrückt ist.
2. Im ersten Durchlauf nach der Pause wird `Image.HAPPY` angezeigt.
3. Die Abfrage von `A` löscht auch den gespeicherten Tastendruck von `B`; deshalb erscheint `Image.SAD` nie.
4. Der Tastendruck von `B` bleibt zunächst gespeichert. Im darauffolgenden Durchlauf wird `Image.SAD` angezeigt und bleibt danach sichtbar.

<Hint when="assessed">
`was_pressed()` merkt sich einen Tastendruck auch nach dem Loslassen. Zuerst liefert die Abfrage
von `A` den Wert `True` und setzt nur den gespeicherten Zustand von `A` zurück.
Der `elif`-Zweig wird übersprungen; `B` bleibt deshalb gespeichert.
Nach der nächsten Pause liefert die Abfrage von `A` den Wert `False`, jene von `B` den Wert `True`.
Danach bleibt `Image.SAD` sichtbar, weil kein weiterer Tastendruck und kein `else`-Zweig das Bild ändern.
</Hint>
</ChoiceAnswer>

<ChoiceAnswer multiple correct={[1, 4]}>
**Beispiel 2**: während `sleep(1000)` wird zuerst kurz `B`
und danach `A` gedrückt.
Welche Aussagen sind korrekt?

1. Im ersten Durchlauf nach der Pause wird `Image.HAPPY` angezeigt, obwohl `B` zuerst gedrückt wurde.
2. Die Tastendrücke werden in ihrer zeitlichen Reihenfolge abgespielt: zuerst `Image.SAD`, dann `Image.HAPPY`.
3. Nur der zuletzt erfolgte Tastendruck wird gespeichert; `Image.SAD` wird deshalb nie angezeigt.
4. Im darauffolgenden Durchlauf wird `Image.SAD` angezeigt. Entscheidend ist hier die Reihenfolge der Abfragen im Code.

<Hint when="assessed">
Beide Tasten speichern unabhängig voneinander, ob sie gedrückt wurden. Die Abfragen liefern
keine gemeinsame zeitlich geordnete Liste der Tastendrücke. Weil `A` im Code zuerst geprüft wird,
erscheint auch in diesem Szenario zuerst `Image.HAPPY` und nach der nächsten Pause `Image.SAD`.
</Hint>
</ChoiceAnswer>

```py
from microbit import *

bilder = [
    Image.PACMAN,
    Image.PITCHFORK,
    Image.RABBIT,
    Image.ROLLERSKATE,
    Image.SAD,
    Image.SCISSORS,
    Image.SILLY,
    Image.SKULL,
    Image.SMILE,
    Image.SNAKE,
    Image.SQUARE,
    Image.SQUARE_SMALL,
    Image.STICKFIGURE,
    Image.SURPRISED,
    Image.SWORD,
    Image.TARGET,
    Image.TORTOISE,
    Image.TRIANGLE,
    Image.TRIANGLE_LEFT,
    Image.TSHIRT
]
bild_index = 0
while True:
    if button_b.was_pressed():
        bild_index = bild_index + 1
    elif button_a.was_pressed():
        bild_index = bild_index - 1

    if bild_index >= len(bilder):
        bild_index = 0
    elif bild_index < 0:
        bild_index = len(bilder) - 1

    display.show(bilder[bild_index])
    sleep(100)
```
</Solution>
