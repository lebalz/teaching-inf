# 2. Listen

Zum Speichern von **mehreren Werten** unter einem **einzigen Namen** werden beim Programmieren Listen oder Arrays verwendet. __Listen__ sind vergleichbar mit einspaltigen Tabellen. Die Zellen in der Tabelle werden als **Elemente** bezeichnet und sind durchnummeriert. So können einzelne Werte, die in der Liste gespeichert sind, voneinander unterschieden werden. Die Nummer eines Elements wird als dessen **Index** bezeichnet.

:::warning[Wichtig]
- Das erste Element in der Liste trägt den Index 0.
- Der Index des letzten Elementes ist somit die Länge der Liste minus 1.
:::

Die folgende Auflistung illustriert dies für eine Liste mit 4 Noten. Die **Länge** der Liste ist **4**, das letzte Element trägt den **Index 3**.

Index
: **Wert**
`0`
: :mdi[arrow-right-thin] `4.5`
`1`
: :mdi[arrow-right-thin] `5`
`2`
: :mdi[arrow-right-thin] `3.5`
`3`
: :mdi[arrow-right-thin] `5.5`

In Python lassen sich Listen mit eckigen Klammern `[ ]` wie folgt erzeugen:

```py live_py slim
noten = [4.5, 5, 3.5, 5.5]
print('Die vierte Note war eine', noten[3])
```

Im Beispiel wird die vierte Note mit dem Index `3` ausgegeben.

:::


:::

:::def[Länge einer Liste: `len(<liste>)`]

```py live_py slim
noten = [4.5, 5, 3.5, 5.5]

print(len(noten))
```
:::


::::def[Schleife über alle Elemente der Liste]
Anstatt mit `range()` einen Schleifeniterator zu erzeugen, kann auch direkt eine
explizite Liste angegeben werden. Die **Laufvariable** nimmt dabei nacheinander die Werte der Liste an.

```py live_py slim
noten = [3.5, 6, 5, 4.5]

for note in noten:
    print(note)
```
:::insight[Laufvariable]
Die Laufvariable `note` nimmt in jedem Schleifendurchlauf den Wert des nächsten Elements der Liste `noten` an.
:::
::::

::::def[Schleife über Listen-Indices]
```py live_py slim
noten = [3.5, 6, 5, 4.5]

länge = len(noten)  # Länge der Liste ermitteln

for i in range(länge):
    print(i, ":", noten[i])
```
:::insight[`range(länge)`]
Für die Arbeit mit Listen ist es sehr praktisch, dass der Schleifenzähler `i` genau die Indexwerte der Liste annimmt.
:::
::::

## Elemente abfragen


:::def[Erstes Element: `<liste>[0]`]
```py live_py slim
noten = [4.5, 5, 3.5, 5.5]
print(noten[0])
```
:::


:::def[Letztes Element `<liste>[-1]`]
```py live_py slim
noten = [4.5, 5, 3.5, 5.5]
print(noten[-1])
# oder gleichbedeutend
print(noten[len(noten) - 1])
```
:::

::::def[Fehler: <span className="badge badge--danger">IndexError</span>]
Fragt man einen Index ab, den es nicht gibt (weil es zu wenige Elemente in der Liste hat), so entsteht ein <span className="badge badge--danger">IndexError</span>.

```py live_py slim
noten = [3.5, 6, 5, 4.5]

# Eine Liste mit 4 Elementen: Grösster Index ist 3
print(noten[4])  # IndexError: list index out of range
```
:::insight[Fehlerbehebung]
- Prüfen Sie die Länge der Liste mit `len(<liste>)`.
- Prüfen Sie, ob der Index kleiner als die Länge der Liste ist.

```py live_py slim
noten = [3.5, 6, 5, 4.5]
if len(noten) > 4:
    print(noten[4])
```
:::

## Elemente Hinzufügen/Entfernen

::::def[hinzufügen: `<liste>.append(<wert>)`]

`append` fügt ein neues Element am **Ende** der Liste hinzu.

```py live_py slim
noten = [4.5, 5, 3.5, 5.5]
print('Ursprünglich', noten)
noten.append(6)
print('Neu', noten)
```
::::

:::def[entfernen: `<liste>.pop()`]
Entfernt das letzte Element der Liste und gibt dieses zurück:

```py live_py slim
noten = [4.5, 5, 3.5, 5.5]
noten.pop()
print('Noten', noten)
```
:::
:::def[alles entfernen: `<liste>.clear()`]
Löscht alle Elemente der Liste:

```py live_py slim
noten = [4.5, 5, 3.5, 5.5]
noten.clear()
print('Noten', noten)
```
:::

## Aufgabe 3: Schneefall

:::tip[Ziel]
Schnee soll herunterfallen, die Schneeflocken sollen dabei zufällig auf der Szene verteilt sein. Die Schneeflocken sollen sich dabei langsam nach unten bewegen.
:::

### Vorbereitung

Damit eine Szene animiert werden kann, muss eine Codesequenz immer wieder aufgerufen werden. Dies kann mit einer `while True` Schleife erreicht werden:

```py
snow = scene.add_icon('snowflake')

while True:
    snow.y = snow.y + 1
    scene.render()
```

**Beachte** dass bei jedem Schleifendurchgang `scene.render()` aufgerufen wird, so dass die Szene aktualisiert wird.

::::aufgabe[Schneefall]
<ProgressState id="b2d81334-d375-4478-adb1-95f6ca2358c7" confirm>
1. Führen Sie das untenstehende Programm aus. Aktuell fällt die Schneeflocke sehr schnell herunter. Fügen Sie nach jeder Aktualisierung der y-Position ein `sleep` ein, welches kurz wartet (Angabe in Sekunden).
2. Können Sie die Schneeflocke auch schief fliegen lassen?
3. Sobald die Schneeflocke unten am BIldschirm angekommen ist, soll sie wieder oben am Bildschirm erscheinen.

   Es braucht sicher eine bedingte Abfrage. Die Szenenhöhe beträgt \`400\` Pixel.

   ```py
   while True:
       snow.y = snow.y + 1
       if snow.y > 400:
           # setze die Position zurück
   ```

   :::

4. Nun sollen regelmässig neue Schneeflocken hinzugefügt werden. Dazu muss der aktuelle Code etwas umgestellt werden:

   1. erstellen Sie eine neue Funktion `neue_schneeflocke` welche der Szene eine neue Schneeflocke oben in der Szene hinzufügt.
      :::details[Hilfe]

      :::
   2. Nach diesem ersten Schritt gibt das Programm einen Fehler aus, da `snow` nun nicht mehr definiert ist. Zudem sollen nun alle Schneeflocken herunterfallen. Dies wird erreicht, indem über eine **Liste aller Schneeflocken iteriert** wird. Diese Liste kann von der Szene abgefragt werden:
      ```py
      while True:
          for snow in scene.icons:
              # bisheriger Code hier einfügen, eingerückt!
      ```
   3. Probieren Sie aus, ob es für mehrere Schneeflocken funktioniert: Fügen Sie zu Beginn drei Schneeflocken hinzu.

      Die drei Schneeflocken werden übereinander gezeichnet. Lösung: die x-Position sollte zu beginn **zufällig** gesetzt werden.
      :::

      :::details[Zufällige Positionierung]
      ```py
      from random import randint
      snow.x = randint(0, 600)
      ```
      :::

5. Nun soll jede Sekunde eine neue Schneeflocke hinzugefügt werden. Also braucht es eine Art Stoppuhr - mit `time()` erhalten wir die Anzahl Sekunden seit dem 1.1.1970, 00\:00 Uhr morgens. Um damit eine Stoppuhr zu bauen, berechnen wir die **differenz** zwischen dem Startzeitpunkt und dem Endzeitpunkt:

   ```py live_pyo slim
   from time import sleep, time

   t0 = time()
   sleep(1)
   now = time()
   print('vergangen:', now - t0)
   ```
