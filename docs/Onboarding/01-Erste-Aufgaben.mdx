# Erste Aufgaben
Um die _Informatikwebseite_ besser kennenzulernen, finden Sie hier eine Reihe von kurzen Einführungsaufgaben.

## Eine erste Aufgabe
:::aufgabe[Wie sehen Aufgaben aus?]
<TaskState id="822799a1-05e7-4e34-a209-78a76b0519a6" />
Wenn eine Kachel so aussieht, wie diese hier, dann handelt es sich um eine Aufgabe. Eine erste Aufgabe haben Sie auf der vorherigen Seite bereits erledigt.

Mit der **Checkbox** oben links können Sie Ihren **Arbeitsstand** angeben. Meistens können Sie aus drei Zuständen auswählen:

:mdi[checkbox-blank-outline]
: **Offen**
: _«Ich habe die Aufgabe noch nicht erledigt.»_
:mdi[checkbox-marked-outline]{.green}
: **Erledigt**
: _«Ich habe die Aufgabe erledigt.»_
:mdi[account-question-outline]{.orange}
: **Frage**
: _«Ich brauche Hilfe von der Lehrperson.»_
: Wenn Sie während des Unterrichts eine Frage haben, melden Sie sich trotzdem bei der Lehrperson!

Am oberen Rand der Webseite sehen Sie einen Überblick über Ihren Arbeitsstand bei allen Aufgaben im aktuellen Artikel. Die Lehrperson kann Ihren Arbeitsstand ebenfalls sehen.

Wenn Sie alles durchgelesen und verstanden haben, klicken Sie die Checkbox jetzt ein paarmal an, um jeden Zustand einmal zu sehen. Sehen Sie, wie sich der Zustand auch in der Übersicht am oberen Seitenrand verändert?

Setzen Sie die Checkbox am Schluss auf **Erledigt**, um die Aufgabe als abgeschlossen zu markieren.
:::

:::warning[Arbeitsstand immer aktualisieren]
Denken Sie daran, Ihren Arbeitsstand **bei jeder Aufgabe immer zu aktualisieren**. So behalten Sie und Ihre Lehrperson den Überblick über Ihren Fortschritt.

Es gilt: Eine Aufgabe ist erst dann erledigt, wenn Sie sie als erledigt markiert haben!
:::

## Alles lesen
Grundsätzlich gilt: **Alles, was auf der _Informatikwebseite_ steht, sollten Sie lesen**. Um Ihnen das Lesen zu erleichtern, sind besonders wichtige Informationen aber oft nochmal spezifisch hervorgehoben. Entweder wird das Wort oder der Satz **fett** geschrieben, oder es wird eine entsprechende _«Kachel»_ verwendet.

Folgende Kacheln werden Sie regelmässig sehen:

:::aufgabe[Aufgabe]
<TaskState id="68b29c3d-4a97-402e-bc49-ea7f9ecfa968" />
Das ist eine Aufgabe - diese Kachel kennen Sie bereits. Sie können sie gleich als erledigt markieren - mehr gibt es hier nicht zu tun 😉.
:::

:::note
Eine Anmerkung zu einem Thema.
:::

:::warning
Das ist eine Warnung. Informationen in solchen Kacheln müssen Sie besonders sorgfältig lesen, da sonst möglicherweise etwas schiefgehen könnte. Eine solche Kachel finden Sie auch oben, gleich unterhalb der ersten Aufgabe.
:::

:::danger
Bei einer Gefahr-Kachel wird es ernst! Lesen Sie die Informationen sehr sorgfältig durch und befolgen Sie die Anweisungen ganz genau.
:::

:::insight[Erkenntnis]
Erkenntnis-Kacheln enthalten Schlüsselergebnisse aus dem Lernstoff. Sie fassen zentrale Informationen zusammen oder ziehen wichtige Schlussfolgerungen.
:::

::::flex
:::info
Das ist eine Zusatzinformation. Diese Kachel enthält wichtige Informationen, die Sie beachten sollten.
:::
::br
:::tip
Das ist ein Tipp. Diese Kachel enthält hilfreiche Zusatzinformationen.
:::
::::
:::definition[Definition]
Ab und zu sehen Sie solche Definitions-Kacheln. Sie enthalten wichtige Begriffe, die Sie kennen sollten.
:::

## Antworten geben
Bei vielen Aufgaben werden Sie Ihre Lösung oder Antwort als Text eingeben. Hier finden Sie zwei Beispiele dazu, wie das aussehen könnte.

Übrigens gilt: Die Lehrperson kann all Ihre Antworten auch sehen.

:::aufgabe[Text schreiben]
<TaskState id='c670335e-6858-4fc6-b0b2-29b265916fbd' />
Unten finden Sie einen einfachen kleinen Text-Editor. Er funktioniert wie eine Mini-Version von _Microsoft Word_ oder _Google Docs_.

Schreiben Sie einen kurzen Text über Ihre Sommerferien. Formatieren Sie Ihren Text nach folgenden Anforderungen:
- Mindestens zwei Überschriften (_Heading 1_ auswählen)
- Mindestens ein Wort **fett**
- Mindestens ein Wort _kursiv_
- Mindestens ein Wort <u>unterstrichen</u>

<QuillV2 id='6284d7aa-0314-4a55-a0f6-fe6e10177e9a' />
:::

:::aufgabe[Alphabet]
<TaskState id='f828cb89-58f6-4e71-989c-0e4163574575' />

Wie lauten die ersten drei Buchstaben unseres Alphabets? Schreiben Sie sie jeweils als Grossbuchstaben hin.

<String id="ca5b2961-6632-48e4-b95d-1912e095b73c" label='1. Buchstabe' sanitizer={(val) => val?.toLowerCase()} solution="a" />
<String id="e2b051f7-6e62-4352-bf86-914d5333ac87" label='2. Buchstabe' sanitizer={(val) => val?.toLowerCase()} solution="b" />
<String id="5eabe076-c6d4-4b46-a499-19475e7baa99" label='3. Buchstabe' sanitizer={(val) => val?.toLowerCase()} solution="c" />

Sobald Sie Ihre Lösungen eingegeben haben, können Sie sie selbstständig kontrollieren, indem Sie auf den __:mdi[help-circle-outline]{.black}__-Knopf drücken.
:::

:::aufgabe[Kacheln reflektieren]
Einige Aufgaben bestehen aus mehreren Schritten. Solche Aufgaben haben keine Checkbox, sondern einen Fortschrittsbalken.

Um einen Schritt als erledigt zu markieren, klicken Sie auf den Punkt links davon. Danach gelangen Sie automatisch zum nächsten Schritt.

<ProgressState id="fc9cb740-4b16-43a6-b7f8-0d74714e5954" confirm preventTogglingFutureSteps>
1. Lesen Sie den Abschnitt [Alles lesen](#alles-lesen) (nochmal) durch.
2. Überlegen Sie sich, was für Informationen Sie wohl in den «Warnung»- und «Gefahr»-Kacheln finden werden.
3. Tauschen Sie sich kurz mit Ihrer Nachbar:in darüber aus.
4. Fassen Sie Ihre Erkenntnisse unten im Textfeld in 1-2 Sätzen zusammen.
5. Sobald Sie mit Ihrer Antwort zufrieden sind, können Sie ganz unten die Lösung aufklappen und Ihre Antwort überprüfen.
6. Sobald Sie den letzten Schritt (also diesen hier) als erledigt markieren, ist die gesamte Aufgabe als erledigt markiert. Das sehen Sie auch in der Übersicht am oberen Seitenrand.
</ProgressState>

<QuillV2 id="50bb33a4-ca8d-418f-a1c8-0dad473071ba" />

<Solution id="5366afab-7cd0-4898-9cb6-485db2ead47c">
Die «Warnung»- und «Gefahr»-Kacheln enthalten Hinweise auf mögliche Probleme oder Fehler, die auftreten können, wenn Sie die Anweisungen nicht genau befolgen. Sie enthalten allenfalls auch Erinnerungen an wichtige Termine oder Anforderungen, die Sie beachten müssen.
</Solution>
:::

:::warning[Der richtige Umgang mit Lösungen]
In der letzten Aufgabe haben Sie eine Lösung aufklappen können. Das ist eine **Lösungshilfe**. Sie hilft Ihnen, Ihre Antwort zu überprüfen. Je nach Aufgabe enthält sie die korrekte Antwort, oder einfach eine mögliche Lösung, die Sie mit Ihrer vergleichen können.

Folgende Dinge müssen Sie beachten:
- Meistens stehen die Lösungen nicht von Anfang an zur Verfügung. Die Lehrperson gibt sie erst frei, wenn Sie die Aufgabe bearbeitet haben.
- Die Lösungen sind dazu da, dass Sie Ihre eigenen Antworten **überprüfen** und **verbessern** können. Sie sollten sie also nicht nur kurz anschauen oder einfach abschreiben, sondern damit Ihre eigene Lösung überarbeiten, wenn sie noch nicht ganz korrekt ist.
:::
